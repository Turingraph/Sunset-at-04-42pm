`corpus/` contains all of the compatible inputs file for this Git repo.

There are 2 types of compatible files
1.	`.fdf` file (where it contains the integers separated by space. for represent 3D isometric/prism object, you can also add 8 digits hex number for specify the cells).
2.	`.txt` file (where it contains printable characters, each character represent the height of cell for 3D isometric/prism object)

This directory contains 4 subdirectories
1.	`ascii/`
*	Describtion: other artistic txt files made by me and Figlet output (https://textarttools.com/Figletfontstool/).
2.	`fdf/`
*	Describtion: fdf files made by 42 Coding school (https://en-wikipedia-org.translate.goog/wiki/42_(school)?_x_tr_sl=en&_x_tr_tl=th&_x_tr_hl=th&_x_tr_pto=tc)
3.	`figlet_rozzo/`
*	Describtion: Figlet output (https://textarttools.com/Figletfontstool/) with `Rozzo` font.
4.	`mathart/`
*	Describtion: The output of this Git repo (`mathart` part). However, the `mathart` is removed because I have to refactor the `mathart` after developing user manual at some point.

Also `aislop.md` contains the ChatGPT advice on how to allow user to use `piskel` file as the input for this Git repo as a part of future features.
